# 🎓 College Learning Management System (LMS)

A **College Learning Management System (LMS)** built using the **MERN Stack** that allows administrators, instructors, and students to manage courses, track attendance, and interact through a structured academic platform.

This project demonstrates a **role-based dashboard system** with modern UI and real-world LMS functionalities.

---

## 🚀 Features

### 🔐 Authentication & Roles
- Role-based login system
- Admin, Instructor, and Student access
- Secure authentication flow

### 👨‍💼 Admin Dashboard
- Manage teachers
- Manage students
- Assign subjects to teachers
- Activate / deactivate user accounts

### 👨‍🏫 Instructor Features
- Editable instructor profile
- Upload and manage courses
- View assigned subjects

### 👨‍🎓 Student Features
- View available courses
- Check attendance
- Access learning materials

### 📊 Attendance Management
- Mark student attendance
- "Mark All Present" option
- Attendance summary dashboard

### 📚 Course Management
- Upload courses
- Assign subjects
- Manage course details

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/ravitharun/edu-lms-mern.git
```

### 2. Install dependencies

Frontend:

```bash
cd frontend
npm install
```

Backend:

```bash
cd backend
npm install
```

### 3. Run the project

Backend:

```bash
npm run dev
```

Frontend:

```bash
npm start
```
